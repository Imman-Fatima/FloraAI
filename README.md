# 🌸 FloraAI – AI-Based Flower Classification App

## Project Overview
FloraAI is an Android application that uses Artificial Intelligence and Machine Learning to identify flowers from images. It uses a custom-trained TensorFlow Lite model to perform image classification directly on an Android device.

## Features
- Select images from the device gallery.
- Identify different flower categories using AI.
- Display prediction results and confidence scores.
- Detect non-flower images.
- Save identification history with image, name, and date/time.
- View previously identified images.
- Simple and user-friendly interface.

## Supported Classes
1. Daisy
2. Dandelion
3. Not Flower
4. Rose
5. Sunflower
6. Tulip

## Technologies Used
- Java
- Android Studio
- TensorFlow Lite
- Python
- Google Colab
- Machine Learning / Deep Learning

## Model Information
- Model format: TensorFlow Lite (.tflite)
- Input image size: 224 × 224
- Classification type: Multi-class image classification
- Model trained using a flower image dataset.

## Android Application
The application allows users to select an image, run AI-based classification, view the prediction and confidence score, and access previously saved identification records.

## Project Structure
- `app/src/main/java/` – Java source code
- `app/src/main/res/` – Application layouts and resources
- `app/src/main/assets/` – TensorFlow Lite model and flower labels

## How to Run
1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle synchronization to complete.
4. Run the application on an Android emulator or physical device.
